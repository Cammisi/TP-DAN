# Trabajo práctico integrador

# Objetivo: realizar una aplicación distribuida basada en microservicios. El

## contexto y problema para resolver será propuesto por el grupo.

## Grupos: 3 personas.

# Requisitos obligatorios:

- Distribuir la aplicación en al menos 3 microservicios spring boot y un frontend.
- Usar al menos 1 base de datos SQL y 1 base de datos NO SQL. Dos microservicios distintos pueden compartir la misma base de datos, pero un microservicio no puede acceder a 2 bases de datos. (Respetar el principio de "single source of true").
- Usar mensajería asincrónica. 
- Ejecutar las aplicaciones detrás de spring cloud Gateway y Eureka Ejecutar las aplicaciones en contenedores Docker
- Implementar seguridad Implementar un almacén centralizado de logs 
- Implementar telemetría de métricas de rendimiento.


Además, deberá agregar al menos una de las siguientes características

| Serverless | - | Resilience4J | - | Kubernetes | - | CQRS |

# Entrega:

- Repositorio git con el proyecto y coloquio y presentación de la implementación
